خطوات رفع المشروع إلى Git & GitHub

دليل سريع لمبتدئي التطوير والبرمجة

1 تهيئة المستودع (Initialize)

قم بفتح موجه الأوامر (Terminal) داخل مجلد مشروعك واكتب الأمر التالي لإنشاء المستودع المحلي:

git init

2 إضافة الملفات (Stage Files)

تجهيز كافة الملفات وتتبعها داخل الـ Staging Area تمهيداً لحفظها:

git add .

3 حفظ التغييرات (Commit)

تسجيل نسخة تحفظ التغييرات مع كتابة رسالة توضيحية لما تم إنجازه:

git commit -m "First commit - Add project files"

4 ربط المستودع البعيد (Remote Add)

ربط مجلدك المحلي بمستودع GitHub الفارق بعد إنشائه على الموقع:

git remote add origin https://github.com/username/repository-name.git

5 رفع الكود (Push)

إرسال التغييرات المعتمدة إلى الفرع الرئيسي (main) على GitHub:

git push -u origin main
